# ExploreHub – Travel Discovery & Trip Planner

ExploreHub is a responsive travel discovery website that helps users explore destinations and plan their trips.

## Features

- Responsive website layout
- Destination cards with images and details
- Destination data stored in JSON
- Search and filter functionality (to be implemented)
- Favorites and trip planning features (to be implemented)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON

## Project Structure

- `index.html` – Website structure
- `style.css` – Website styling and responsive design
- `script.js` – JavaScript functionality
- `destinations.json` – Sample destination data
